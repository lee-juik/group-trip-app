# 그룹 여행 계획 앱 (프로토타입)

여러 명이 함께 여행 정보를 모으고, 비밀 투표로 정하고, 날짜별 일정표로 정리하는 앱.

## 화면
- **수집함**: 인스타 링크와 캡션을 붙여넣으면 장소 카드를 만든다. 같은 이름은 자동으로 합치고 "가고 싶다" 수로 정렬한다.
- **투표**: 수집함 후보로 비밀 투표를 연다. 결과는 전원 투표 또는 마감 때만 공개, 과반수로 결정, 과반이 없으면 상위 2개로 재투표.
- **일정**: 날짜별 빈 일정표에 항공편과 일정을 넣는다. 일정 사이에 대중교통(노선, 출발/도착 시간)을 표시하고, 구글 지도 대중교통 길찾기로 실제 시간표를 연다.

지금은 서버 없이 기기 안에서만 동작하며, 삿포로 샘플 데이터가 들어 있다. 샘플의 교통 시간은 예시 값이다.

## 실행
```bash
npm install
npx expo start      # 휴대폰의 Expo Go 앱으로 QR 코드 스캔
```
